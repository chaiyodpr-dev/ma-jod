# Ma-Jod: บอท AI จดบันทึกประชุม

บอทที่เข้าห้องประชุม Microsoft Teams ผ่านเว็บแบบ guest แล้วอัดเสียงทั้งประชุมเก็บเป็นไฟล์ เพื่อนำไปถอดเสียงภาษาไทยและสรุปรายงานการประชุมต่อ

ตอนนี้เป็นเฟสแรก: **เข้าห้อง Teams + อัดเสียง** ยังไม่มีการถอดเสียง สรุป หรือหน้าเว็บ

## บอททำอะไร

1. เปิดลิงก์ประชุมด้วย Chromium (ควบคุมด้วย Playwright) แล้วกด "Continue on this browser"
2. ใส่ชื่อ `Ma-Jod AI (บันทึกประชุม)` ปิดไมค์และกล้อง แล้วกด Join
3. รอใน Lobby จนเจ้าของห้องกด Admit (ค่าเริ่มต้นรอสูงสุด 10 นาที)
4. อัดเสียงทุกคนในห้องจาก WebRTC ลงไฟล์ `audio.webm` (Opus) ทุก 10 วินาที
5. ออกจากห้องเมื่อประชุมจบ ถูกเชิญออก อยู่คนเดียวเกิน 3 นาที หรือครบ 3 ชั่วโมง

ผลลัพธ์อยู่ที่ `recordings/<เวลา>/`:

| ไฟล์ | คืออะไร |
| --- | --- |
| `audio.webm` | เสียงประชุมทั้งหมด |
| `events.jsonl` | log ทุกขั้นตอน (เข้า Lobby, เริ่มอัด, จบเพราะอะไร) |
| `error.png` | ภาพหน้าจอตอนเกิดปัญหา (มีเฉพาะเมื่อพัง) |

## วิธีรัน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npx playwright install chromium
node src/bot.js "<ลิงก์ประชุม Teams>"
```

ตัวเลือก:

```
--name <text>          ชื่อบอทที่แสดงในห้อง
--out <dir>            โฟลเดอร์เก็บไฟล์ (ค่าเริ่มต้น recordings)
--lobby-minutes <n>    รอ Admit สูงสุด n นาที (10)
--alone-minutes <n>    ออกเมื่ออยู่คนเดียว n นาที (3)
--max-minutes <n>      หยุดบังคับเมื่อครบ n นาที (180)
--headful              เปิดหน้าต่าง browser ให้เห็น (ใช้ตอน debug)
```

กด Ctrl+C หนึ่งครั้งเพื่อให้บอทหยุดอัด บันทึกไฟล์ และออกจากห้องอย่างเรียบร้อย

### รันด้วย Docker (สำหรับ server)

```bash
docker build -t ma-jod-bot .
docker run --rm -v "$PWD/recordings:/app/recordings" ma-jod-bot "<ลิงก์ประชุม Teams>"
```

## ทดสอบ

```bash
npm test
```

ทดสอบระบบอัดเสียงโดยไม่ต้องใช้ Teams: จำลองการโทร WebRTC ในหน้าเว็บ แล้วตรวจว่าไฟล์ที่อัดได้เป็น Opus และมีเสียงจริง ไม่ใช่ความเงียบ

## ข้อควรรู้

- Teams เปลี่ยนหน้าเว็บบ่อย ถ้าบอทหาปุ่มไม่เจอ ให้ดู `error.png` แล้วแก้ selector ใน `src/teams.js`
- องค์กรที่ปิด anonymous join บอทจะเข้าไม่ได้
- ชื่อบอทบอกว่ากำลังบันทึก แต่ควรแจ้งผู้เข้าประชุมด้วยตามหลัก PDPA
